AppDatabase diagram

A simple view of the Drift-backed SQLite schema. Primary keys are auto-incremented, and fields marked nullable can be stored without a value.

One-to-many Each saved item belongs to exactly one collection.

updated_atDATETIMERequired

Library ordering

saved_items is streamed by createdAt DESC.

Collection ordering

collections is streamed by isPinned DESC, then updatedAt DESC.

URL requirement

link and video rows require url; note rows may store it as NULL.

Markdown requirement

note rows require markdown; link and video rows may store it as NULL.
