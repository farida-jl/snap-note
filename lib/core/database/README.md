# Database module

This folder contains the local Drift/SQLite database. `app_database.dart` is the
public entry point imported by the rest of the app.

## Structure

```text
database/
├── app_database.dart
├── app_database.g.dart
├── connection/
│   └── database_connection.dart
├── migrations/
│   └── app_database_migrations.dart
├── queries/
│   └── app_database_queries.dart
├── seed/
│   └── app_database_seed.dart
└── tables/
    ├── collections_table.dart
    └── saved_items_table.dart
```

- `app_database.dart` composes the database and owns the schema version.
- `app_database.g.dart` is generated by Drift and must not be edited manually.
- `connection/` opens the platform database file.
- `migrations/` upgrades older schemas without losing existing data.
- `queries/` contains reusable reactive reads exposed to data sources.
- `seed/` contains development/demo data initialization.
- `tables/` contains one schema definition per database table.

## Changing the schema

1. Update the relevant file in `tables/`.
2. Increase `schemaVersion` in `app_database.dart`.
3. Add an incremental migration in `migrations/`.
4. Regenerate Drift code:

   ```sh
   dart run build_runner build --delete-conflicting-outputs
   ```

5. Run `flutter analyze` and `flutter test`.
